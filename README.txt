Carpeta de fotos de las habitaciones.

Sube aqui las fotos de cada habitacion (formato .jpg o .png, ideal menos de 1MB
cada una para que la web cargue rapido). El nombre del archivo tiene que
coincidir exactamente con lo que escribas en la columna "photo" del Google
Sheet de habitaciones (por ejemplo: cm22-1.jpg).

Como subir fotos aqui:
1. Ve a github.com/mrrzfrnndz/madrid-student-living
2. Entra en la carpeta "images"
3. "Add file" -> "Upload files"
4. Arrastra las fotos y dale a "Commit changes"

No hace falta tocar nada mas: en cuanto la foto esta aqui con el nombre
correcto (y el Google Sheet apunta a ese nombre), aparece sola en la web.
